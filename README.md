# 🎵 Spotify Clone – Web Player

A responsive **Spotify Web Player Clone** built using **HTML, CSS, and JavaScript**.  
This project mimics the core UI and audio playback features of Spotify.

---
# ⭐ If you like this project, don’t forget to star the repo!

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
## 🚀 Features

- 🎧 Play / Pause music
- ⏱️ Real-time progress bar
- 🕒 Current time & total duration display
- 🔊 Volume control
- 🎶 Click cards to play different songs
- 📱 Responsive UI (desktop friendly)
- 🎨 Spotify-like dark theme design

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **Font Awesome Icons**
- **Google Fonts (Montserrat)**
